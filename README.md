# TOKYO Management — Prototype

نسخة تجريبية عملية لنظام إدارة طوكيو بواجهة عربية RTL أبيض/أسود.

## التشغيل
يتطلب Node.js 22 أو أحدث.

```bash
npm install
npm start
```

ثم افتح: `http://localhost:3000`

## حساب المدير التجريبي
- Username: `admin`
- Password: `Tokyo@2026`

غيّر كلمة المرور قبل الاستخدام الفعلي.

## الموجود في النسخة
- لوحة رئيسية.
- بحث شامل باسم الزبون/الهاتف/العنوان ويعرض العقود والقياسات والمعمل.
- زبائن وعقود مع طباعة عقد A4 ومكان توقيع وبصمة.
- قياسات وملاحظات المواقع والنقاط.
- حضور وانصراف مع وقت النظام والموقع والسيلفي عند الإمكان.
- مصروفات معرض/معمل.
- ترتيب أعمال المعمل وقوائم المواد والنواقص.
- ملاحظات عامة وعاجلة.
- موظفون وصلاحيات للمدير.
- قاعدة بيانات SQLite محلية في `data/tokyo.db`.

هذه نسخة Prototype لاعتماد الشكل والوظائف قبل تحويلها إلى تطبيق مثبت على الهاتف والكمبيوتر.
