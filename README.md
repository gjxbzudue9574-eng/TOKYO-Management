# نظام إدارة طوكيو v2
نسخة MVP قابلة للتشغيل: Node.js + Express + SQLite، تسجيل دخول وصلاحيات، حضور وانصراف بالموقع والسيلفي، الزبائن، القياسات، الوصولات، الملاحظات والمصروفات.
الحساب الأولي: admin / 1234. يجب تغيير كلمة المرور قبل الاستخدام الفعلي.
للنشر استخدم استضافة Node.js مع HTTPS وتخزين دائم لقاعدة البيانات، واضبط SESSION_SECRET بقيمة قوية.
