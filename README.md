# TOKYO Management — Final v3

نسخة تشغيلية متكاملة (MVP) لنظام إدارة شركة طوكيو، بواجهة عربية RTL أبيض/أسود.

## المزايا الموجودة
- تسجيل الدخول والحسابات.
- صلاحيات مستقلة لكل موظف.
- البحث الشامل باسم الزبون/الهاتف/رقم الملف وإظهار ملفه الكامل.
- ملفات الزبائن.
- القياسات: مربع/مستطيل/أضلاع، أبعاد، ارتفاع المطبخ، وعناصر مثل باب/شباك/ماء/كهرباء/ساحبة/طباخ/فرن/مايكرو/غسالة/ثلاجة/مجمدة.
- العقود والوصولات، 7 ملاحظات، المبالغ، المواعيد، التصميمات والإضافات.
- عقد A4 قابل للطباعة، وتبقى التواقيع والبصمة فارغة للاستخدام بعد الطباعة.
- الدوام: GPS + سيلفي + وقت الخادم.
- المعرض: مصروفات وملاحظات.
- المعمل: جدول العمل، المواد، النواقص، المصروفات.
- ملاحظات الشركة + العاجل والمثبت.
- المستخدمون والصلاحيات.
- التقارير.
- إعدادات اسم الشركة وساعات الدوام.
- PWA قابلة للإضافة للشاشة الرئيسية بعد نشرها على HTTPS.

## التشغيل
1. ثبّت Node.js 20+.
2. داخل المجلد:
   npm install
3. ثم:
   npm start
4. افتح:
   http://localhost:3000

## للنشر الحقيقي
استخدم استضافة تدعم Node.js + تخزين دائم لملف SQLite، واضبط:
- SESSION_SECRET إلى قيمة قوية.
- DB_PATH إلى مسار قرص دائم.
- HTTPS مطلوب للكاميرا والموقع على الهاتف.

## ملاحظات إنتاجية مهمة
هذه نسخة MVP تشغيلية. للاستخدام التجاري طويل الأمد يُنصح بإضافة:
- نسخ احتياطي خارجي.
- تخزين ملفات/صور في خدمة Object Storage.
- سجل تدقيق Audit Log.
- تغيير كلمة مرور المدير من داخل الإعدادات.

- تشفير/سياسة احتفاظ ببيانات السيلفي والموقع وفق القانون وسياسة الشركة.
